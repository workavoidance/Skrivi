# Reader Voice Lab 0.2.0 build report

Built 2026-09-08. Uses unchanged VoxCPM2 Q4 weights and CrispASR v0.8.32 Windows CPU binaries from 0.1.0. No additional model download. See BUILD_REPORT.md for historical 0.1.0 measurements and runtime provenance; its old voice-gap section is superseded by this report and VOICE_GUIDE.md.

## Changes

- Persistent variation seed, diffusion steps and guidance controls.
- Explicitly permitted reference voice import, persistent local copy, reference format validation and default-voice reset.
- Reference filenames are generated by the app. The runtime uses a dedicated voices working directory and voice-dir, resolving its WAV references locally.
- UI labels synthetic speech; reference import includes consent and shared-output disclosure confirmation.
- Default playback remains native 48 kHz mono PCM16, without speed/pitch changes.
- No changes to selection, clipboard fallback, hotkey, model identity or model persistence.

## Verification

Windows x64 executable and core compiled on Linux with Roslyn/.NET Framework 4.8 references. Eleven core checks passed, including native output validation, reference parsing and truncated-reference rejection.

The same-version Linux CPU runtime produced the following WAVs with the pinned model, four threads, steps 10, guidance 2.0 and unchanged playback speed. Input: `Hei! Dette er en prøve på norsk tale.`

| Test | Generation seconds | Audio seconds |
| --- | ---: | ---: |
| Default, seed 42 | 16.80 | 3.24 |
| Default, seed 123 | 13.99 | 3.08 |
| Reference conditioning, seed 42 | 24.82 | 2.92 |

All output was 48 kHz mono PCM16. Different seeds and reference conditioning yielded distinct output hashes. The reference was an AI-generated default-voice sample, not a female speaker. Peak runtime RSS across this run was 3,139,182,592 bytes (3.14 GB). These are shared Linux server CPU figures, not Windows laptop measurements. See voice-benchmark.json for exact values.

The model remains 1,689,498,432 bytes. The app package excludes it and reuses LocalAppData. Runtime files remain approximately 19.27 MB uncompressed. New code and source add only a small amount; final package size is given with delivery.

## Not tested here

Windows UI rendering, settings persistence on Windows, reference file picker, Windows playback, hotkey/clipboard regression tests, GPU behavior, female Oslo similarity and comparative listening quality. Non-default guidance/step values are wired to the runtime's documented source-level environment controls, but were not acoustically benchmarked in this run. A different byte hash is not proof of improved quality or a successful female-voice match.

No female preset or NbAiLab model is bundled. A permitted female reference is still needed for that experiment. No artificial pitch shift or alternate TTS model was substituted.
